# Arduino UNO Calculator

A simple calculator made using an Arduino UNO, 4×4 keypad, and 16×2 I2C LCD.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Keypad input
- LCD output

## Components

- Arduino UNO
- 4×4 Keypad
- 16×2 I2C LCD
- Jumper wires

## Controls

```text
A = +
B = -
C = ×
D = ÷
# = Calculate
* = Clear
