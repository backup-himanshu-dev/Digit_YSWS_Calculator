# Arduino UNO Calculator

A simple calculator made using an Arduino UNO, 4×4 keypad, and 16×2 I2C LCD.

## Components

* Arduino UNO
* 4×4 Keypad
* 16×2 I2C LCD
* Jumper Wires

## 🎛️ Controls

- **A** = `+`
- **B** = `-`
- **C** = `×`
- **D** = `÷`
- **#** = Calculate
- `*` = Clear
