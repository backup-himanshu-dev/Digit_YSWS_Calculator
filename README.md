# Arduino UNO Calculator

A simple calculator made using an Arduino UNO, 4×4 keypad, and 16×2 I2C LCD. Type in the numbers on the keypad, choose an operation, click equals, and the answer will appear on the LCD!

## Components

* Arduino UNO (main controller)
* 4×4 Keypad
* 16×2 I2C LCD
* Jumper Wires

## 🎛️ Controls
- **A** = `+`
- **B** = `-`
- **C** = `×`
- **D** = `÷`
- **#** = Calculate
- `*` = Clear
